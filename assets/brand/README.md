# Caicos Media logo files (web-ready)

Master copies of the Caicos Media logo, exported from the originals supplied by Estefania (Nov 2026).
All are transparent PNGs, cropped tight, in the three brand-safe colours.

| File | Use |
|---|---|
| `logotype-horizontal-*.png` | Dolphin + "CAICOS MEDIA" stacked text. Default for headers. |
| `logogram-dolphin-*.png` | Dolphin icon only. Favicons, app icons, watermarks. |
| `wordmark-one-line-*.png` | "CAICOS MEDIA" on one line, no dolphin. Narrow bars, footers. |
| `wordmark-stacked-*.png` | "CAICOS / MEDIA" stacked, no dolphin. |

Colours: `-deep-blue` = Caribbean Deep Blue #00124C (on light backgrounds), `-white` (on dark or photo backgrounds), `-black` (print / mono).
Favicon rule from the brand guideline: white dolphin on Caribbean Light Blue #0089FF rounded square (see `../favicon-32.png`, `../icon-512.png`).
